# History of Gait

A simple reading list on legged locomotion, gait generation, balance, control, learning-based locomotion, and recent vision-language-action approaches for embodied mobility.

## 1. Classical Foundations

- **Zero Moment Point**
  - Vukobratović, M. and Borovac, B.
  - Early work on the Zero Moment Point concept for biped stability.
  - Link: https://www.cs.cmu.edu/~cga/legs/vukobratovic.pdf

- **Passive Dynamic Walking**
  - Collins, S., Ruina, A., Tedrake, R., and Wisse, M.
  - Shows efficient walking behavior emerging from passive mechanics.
  - Link: https://www.nature.com/articles/nature04113

- **Capture Point / Foot Placement for Balance**
  - Pratt, J. and Goswami, A.
  - Introduces capture point ideas for balancing humanoid robots.
  - Link: http://www.ambarish.com/paper/Pratt_Goswami_Humanoids2006.pdf

## 8. Suggested Reading Order

1. Start with Zero Moment Point.
2. Read passive dynamic walking.
3. Read capture point / foot placement control.
4. Move to humanoid and quadruped control papers.
5. Study reinforcement learning for locomotion.
6. Study sim-to-real transfer.
7. Finish with vision-language-action and foundation-model locomotion papers.
